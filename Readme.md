# YoLoDreamFox — портфолио верстальщика

Адаптивная страница-визитка Junior-верстальщика: проекты, навыки, опыт и контакты.
Сверстана вручную на HTML и SCSS, весь контент подгружается из файлов данных.

English version: [Readme.en.md](Readme.en.md)

**Демо:** https://yolodreamfox.github.io/portfolio/

![Светлая и тёмная тема](docs/preview.png)

## Возможности

- Адаптивная вёрстка: версии для компьютера и телефона
- Светлая и тёмная темы: по умолчанию берётся системная настройка, выбор пользователя запоминается
- Переключение языка (русский / английский): тексты хранятся в YAML-файлах
- Контент отдельно от разметки: проекты, навыки и опыт подставляются из `data.js`
- Опыт сортируется от свежего к старому, срок работы считается автоматически
- Шкалы навыков и их анимация сделаны на CSS
- Карточки навыков прокручиваются кнопками, кнопки появляются только когда карточки не помещаются
- Окно «Обо мне» на элементе `<dialog>`

## Стек

HTML5, SCSS (Sass), JavaScript (ES-модули, без фреймворков), js-yaml, Font Awesome.
Шрифты: Caveat, Anonymous Pro.

## Структура проекта

```
├── index.html
├── css/            скомпилированные стили
├── scss/           исходники стилей (миксины, анимации, темы)
├── js/             модули: рендер карточек, переводы, тема, наблюдатели
├── data/
│   ├── data.js     проекты, навыки, опыт
│   ├── picture/    скриншоты работ, аватар
│   └── locales/    ru.yaml, en.yaml
└── libs/           js-yaml, Font Awesome, шрифты
```

## Запуск локально

1. Склонировать репозиторий.
2. Запустить локальный сервер. ES-модули и `fetch` не работают, если открыть `index.html` двойным кликом.
   Подойдёт расширение Live Server в VS Code или `python -m http.server` в папке проекта.
3. Открыть `http://localhost:8000` (или адрес, который покажет Live Server).

## Сборка стилей

Стили компилируются расширением Watch Sass для VS Code. Готовый CSS лежит в репозитории, поэтому для просмотра сборка не нужна.

## Как изменить содержимое

- **Проект.** Добавить объект в массив `projects` в `data.js` (идентификатор, картинка, названия и ключ описания, стек, ссылки), вкладку в разметке и добавить ключ в перевод.
- **Навык.** Добавить запись в нужную группу в `data.js`: название и уровень от 0 до 100.
- **Опыт.** Добавить место работы с датами начала и конца. Для текущего места конец равен `null`.
- **Текст интерфейса.** Правится в `data/locales/ru.yaml` и `data/locales/en.yaml`, ключи совпадают с атрибутами `data-i18n` в разметке.
